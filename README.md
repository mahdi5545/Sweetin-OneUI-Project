# Sweetin One UI Project

Experimental research and development project focused on exploring the feasibility of porting Samsung One UI to the Xiaomi Redmi Note 10 Pro Indian variant (sweetin).

## Target Device

| Property | Value |
|---|---|
| Device | Xiaomi Redmi Note 10 Pro |
| Variant | Indian |
| Model | M2101K6I |
| Codename | sweetin |
| SoC | Qualcomm Snapdragon 732G |

## Project Goals

- Investigate the technical feasibility of a One UI port.
- Study Android architecture, firmware structures, and hardware interfaces.
- Develop custom development and analysis tools using Dart.
- Build a reusable toolkit for firmware research.
- Document experiments, findings, and development progress.

## Development Tools

- Dart
- Flutter (planned for future GUI tools)
- Git and GitHub
- Android Debug Bridge (ADB)
- Fastboot

## Project Structure

```text
ROM-Development/
├── device/       # Device-specific documentation

├── donors/       # Reference firmware (local only)

├── logs/         # Experiment logs (local only)

├── source/       # Source code
├── tools/

│   └── external/ # External utilities

```

## Current Status

**Early research and tooling phase.** No working One UI port is currently claimed or guaranteed.

## Important Notes

- This project is experimental and provided for educational and research purposes.
- Device modifications and firmware flashing can permanently damage a device.
- Do not upload proprietary firmware, copyrighted binaries, private keys, credentials, or personal device data.
- Compatibility and feasibility must be established through testing; they are not assumed.
